1. ĐỊNH NGHĨA CĂN BẬC BA

Căn bậc ba của một số a là số x sao cho x³ = a. Ký hiệu: x = ∛a

📐 Định nghĩa chính thức:

Cho số a bất kỳ:

∛a = x ⇔ x³ = a

Điều kiện: a ∈ ℝ (mọi số thực)

Số dương

Có căn bậc ba dương

∛8 = 2

Số âm

Có căn bậc ba âm

∛(-8) = -2

Số 0

Căn bậc ba bằng 0

∛0 = 0

📝 Ví dụ minh họa:

  • • ∛27 = 3 (vì 3³ = 27)
  • • ∛64 = 4 (vì 4³ = 64)
  • • ∛(-27) = -3 (vì (-3)³ = -27)
  • • ∛0 = 0 (vì 0³ = 0)

2. TÍNH CHẤT CỦA CĂN BẬC BA

Tính chất cơ bản

  • • ∛(a·b) = ∛a · ∛b
  • • ∛(a/b) = ∛a / ∛b (b ≠ 0)
  • • ∛(a³) = a
  • • (∛a)³ = a

So với căn bậc hai

  • • Xác định với mọi số thực
  • • Giữ nguyên dấu của số
  • • Luôn có nghiệm duy nhất
  • • Không cần điều kiện xác định

📐 Các hằng đẳng thức quan trọng:

  • • ∛(a³) = a (với mọi a)
  • • ∛(a·b) = ∛a · ∛b
  • • ∛(a/b) = ∛a / ∛b (b ≠ 0)
  • • ∛(aⁿ) = (∛a)ⁿ

📝 So sánh các căn bậc ba:

  • • ∛a < ∛b ⇔ a < b
  • • ∛a = ∛b ⇔ a = b
  • • ∛a > 0 ⇔ a > 0
  • • ∛a = 0 ⇔ a = 0

3. CÁC PHÉP TOÁN VỚI CĂN BẬC BA

Nhân chia

∛a · ∛b = ∛(ab)

∛a / ∛b = ∛(a/b)

Lũy thừa

(∛a)ⁿ = ∛(aⁿ)

Ví dụ: (∛2)³ = 2

Đưa thừa số

a∛b = ∛(a³b)

Ví dụ: 2∛3 = ∛24

📝 Các bước rút gọn biểu thức:

  1. Phân tích số dưới căn thành lập phương
  2. Đưa thừa số ra ngoài căn
  3. Thực hiện phép tính
  4. Rút gọn kết quả

4. VÍ DỤ MINH HỌA

Ví dụ 1: Tính giá trị

Tính: ∛27 + ∛64 - ∛8

Lời giải:

∛27 = 3, ∛64 = 4, ∛8 = 2

Kết quả: 3 + 4 - 2 = 5

Ví dụ 2: Rút gọn biểu thức

Rút gọn: ∛(16·2)

Lời giải:

∛(16·2) = ∛32 = ∛(8×4)

= 2∛4

Ví dụ 3: So sánh

So sánh: ∛27 và ∛64

Lời giải:

Vì 27 < 64

Nên ∛27 < ∛64

3 < 4
