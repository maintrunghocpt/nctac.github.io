1. KHÁI NIỆM TRỤC CĂN THỨC

Trục căn thức ở mẫu là phép biến đổi nhằm loại bỏ dấu căn ở mẫu số của phân thức, giúp biểu thức đơn giản hơn và dễ tính toán hơn.

📐 Mục đích của việc trục căn:

  • • Loại bỏ căn ở mẫu số
  • • Đơn giản hóa biểu thức
  • • Dễ dàng thực hiện các phép tính
  • • So sánh các phân thức chứa căn

Dạng 1: A/√B

Nhân với √B/√B

Kết quả: A√B/B

Dạng 2: A/(√B±√C)

Nhân với liên hợp

Kết quả: A(√B∓√C)/(B-C)

Dạng 3: (A±√B)/C

Chia từng số hạng

Kết quả: A/C ± √B/C

2. CÁC DẠNG TRỤC CĂN THỨC

Dạng cơ bản: A/√B

Nhân cả tử và mẫu với √B

A/√B = (A·√B)/(√B·√B) = A√B/B

Ví dụ: 3/√5 = 3√5/5

Dạng liên hợp: A/(√B±√C)

Nhân với biểu thức liên hợp

A/(√B+√C) = A(√B-√C)/(B-C)

Ví dụ: 2/(√3+√2) = 2(√3-√2)

📐 Các công thức quan trọng:

  • • (√A + √B)(√A - √B) = A - B
  • • (√A + √B)² = A + B + 2√(AB)
  • • (√A - √B)² = A + B - 2√(AB)
  • • (A + √B)(A - √B) = A² - B

📝 Ví dụ minh họa:

Ví dụ 1: Trục căn 3/√5

= 3√5/(√5×√5) = 3√5/5

Ví dụ 2: Trục căn 2/(√3+√2)

= 2(√3-√2)/[(√3+√2)(√3-√2)]

= 2(√3-√2)/(3-2) = 2(√3-√2)

3. CÁC BƯỚC TRỤC CĂN THỨC

Quy trình trục căn

  1. Nhận dạng dạng biểu thức
  2. Chọn biểu thức liên hợp phù hợp
  3. Nhân cả tử và mẫu với liên hợp
  4. Rút gọn mẫu số
  5. Rút gọn tử số (nếu có thể)
  6. Rút gọn phân số cuối cùng

📌 Lưu ý quan trọng:

  • • Luôn nhân cả tử và mẫu với cùng biểu thức
  • • Sử dụng hằng đẳng thức để rút gọn mẫu
  • • Kiểm tra điều kiện xác định (B > 0, B ≠ C)
  • • Rút gọn phân số nếu tử và mẫu có ước chung
  • • Kiểm tra lại kết quả cuối cùng

4. VÍ DỤ MINH HỌA

Ví dụ 1: Dạng cơ bản

Trục căn: A = 5/√3

Lời giải:

A = 5√3/(√3×√3)

A = 5√3/3

Ví dụ 2: Dạng liên hợp

Trục căn: B = 3/(√5+√2)

Lời giải:

B = 3(√5-√2)/[(√5+√2)(√5-√2)]

B = 3(√5-√2)/(5-2)

B = 3(√5-√2)/3 = √5-√2

Ví dụ 3: Dạng phức tạp

Trục căn: C = (√2+1)/(√2-1)

Lời giải:

C = (√2+1)²/[(√2-1)(√2+1)]

C = (2+2√2+1)/(2-1)

C = 3 + 2√2
